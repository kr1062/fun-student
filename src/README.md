Запуск фронта(maven -> student -> plugins -> javafx -> двойное нажатие на javafx:run) откроет десктопное окно.

Для входа используйте тестовые аккаунты: `admin@example.com` с паролем `admin` (полный доступ), `teacher@example.com` с паролем `teacher` (только чтение) или `superadmin@example.com` с паролем `superAdmin` (может создавать других пользователей).

С точки зрения функционала фронтенд позволяет делать полный CRUD студентов, искать их в реальном времени через поисковую строку, а также управлять пользователями и назначать им роли(для суперадмина), при этом интерфейс имеет стилизованное оформление.

В проект добавлены тесты трех уровней: юнит-тесты с Mockito для проверки логики сервисов, тесты репозиториев с использованием базы H2 в памяти (чтобы не трогать боевую PostgreSQL) и тесты контроллеров с MockMvc, которые проверяют работу безопасности и коды ответов API.

Помимо изначальных библиотек (Spring Boot, JPA, PostgreSQL, Lombok, JWT), в ходе работы были добавлены JavaFX (javafx-controls и javafx-fxml) для интерфейса, плагин javafx-maven-plugin для удобного запуска, H2 для тестовой базы данных и JUnit 5 с Mockito для написания самих тестов.
